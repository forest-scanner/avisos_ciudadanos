🌳 Análisis de Incidencias de Parques y Arbolado en Madrid
Este proyecto es un script de Python (analisis_madrid_avisa.py) diseñado para analizar y visualizar las incidencias (registros/quejas) relacionadas con "Árboles y parques" en la ciudad de Madrid, utilizando datos públicos en tiempo real.

🎯 Objetivo
El script calcula métricas clave para la gestión urbana y genera gráficos claros, asegurando que los resultados sean estadísticamente robustos.

📊 Métricas Clave
El programa ofrece tres métricas principales por distrito, filtrando los datos para incluir solo los distritos con más de 500 registros para garantizar la fiabilidad estadística:

Registros Absolutos: El número total de incidencias por distrito.

Incidencia Normalizada: Número de registros por cada 1,000 habitantes, permitiendo una comparación justa entre distritos de diferente tamaño poblacional.

Tiempo Medio de Respuesta: El promedio de días que tarda el Ayuntamiento en resolver las incidencias.

✨ Características Principales
Análisis Dinámico: El usuario puede seleccionar el rango de meses a analizar.

Visualización Clara: Genera tres gráficos y sus correspondientes tablas de datos por separado.

Robustez de Datos: Implementa limpieza de nombres de distritos y filtros de umbral para evitar valores anómalos o "ruido" estadístico en las gráficas.
